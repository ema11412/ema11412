<div align="center">

**Space Pirates** es un juego de cartas online de bazas con apuestas, ambientado en el espacio. Cada ronda apuestas cuántas bazas vas a ganar: si aciertas exacto sumas puntos y si fallas, aunque sea por una, los pierdes. Creas una sala, compartes el código y juegas desde el celular con tus amigos. Si faltan jugadores, completas la mesa con bots.
